# Sample CSV Outputs

This directory contains representative CSV outputs generated by the application for each of the four required NSE datasets:

| Sample File | Dataset | Record Count | Description |
|---|---|---|---|
| `sample_top_gainers_losers.csv` | Top Gainers / Losers | 20 records | Top gaining equities (NIFTY 50 index) |
| `sample_upper_band_hitters.csv` | Upper Band Hitters | 152 records | Securities that reached their upper circuit price band |
| `sample_volume_gainers_spurts.csv` | Volume Gainers / Spurts | 25 records | Securities exhibiting significant volume spurts |
| `sample_52_week_high.csv` | 52 Week High — Equity Market | 113 records | Equity market securities touching new 52-week highs |

All sample files were downloaded automatically from live NSE endpoints, validated for schema conformity and non-emptiness, deduplicated, and formatted with standardized column headers.
